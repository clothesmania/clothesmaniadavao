# Editable product choices

Implement inline category and size/variant managers in Products & Inventory, using the existing UI style. Store custom lists in the encrypted workspace snapshot so unused choices survive reload, backup, and cloud sync. Seed legacy categories and sizes without losing products.

1. Add persistent choice helpers, validation, safe rename across current product records, and in-use deletion protection. Preserve historical orders.
2. Add accessible management controls below the filters and connect the product category select and size suggestions to the same lists. Use the existing persistence, audit, and cloud queue.
3. Verify migration, add/rename/delete, duplicates, unsafe labels, and persistence with focused tests; build and inspect the local UI. Record results and commit.

Acceptance: users can add, rename, and delete unused choices; active product assignments block deletion; renaming updates matching inventory without changing stock or sales history. Choices remain in the workspace even without products. No production deployment is included.
