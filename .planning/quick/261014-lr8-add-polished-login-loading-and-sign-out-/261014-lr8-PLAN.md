# Quick Task: Login and Sign-Out Feedback

## Objective
Replace the native browser sign-out confirmation with branded application dialogs and show a five-second sign-in transition after successful local credential validation.

## Scope
- Modify the active standalone UI in `index.html` only.
- Preserve current local authentication and saved-record behavior.
- Provide an explicit sign-out confirmation followed by a short signing-out progress modal.
- Show an accessible sign-in progress modal for five seconds before opening the dashboard.

## Verification
- Run the existing client production build if applicable and inspect standalone HTML/JavaScript syntax.
- Verify the sign-in and sign-out modal markup and handlers are wired to the existing local auth flow.
