# Phase 3 Plan 1: Orders and Legacy Mine Migration

## Objective

Deliver a real local-first order flow with atomic inventory deduction and convert supported legacy orders into queryable local records without losing raw records or sample labels.

## Tasks

1. Extend the Dexie schema and repository with order, stock-out movement, and audit records; implement a transaction-safe order API with product and free-form lines.
2. Convert legacy mines, associated downpayments/status, and session references into stable local records while preserving original IDs and the complete source archive; make migration retry-safe and preview counts/types before commit.
3. Add local POS/order UI with buyer, product/free-form item, quantity, amount, session/seller, and initial collection inputs. Display orders and remaining stock.
4. Add Supabase tables, ownership/RLS, and an idempotent event RPC for products, stock movements, orders, and payments.
5. Test oversell rejection, free-form behavior, atomic failure rollback, paid/unpaid migration mapping, seeded sample exclusion, and duplicate migration safety.

## Verification

- `npm test` from `client/`.
- `npm run build` from `client/`.
- Simulate offline writes and confirm IndexedDB contains order, stock movement, payment, audit, and outbox rows before any network call.
- Verify imported legacy IDs and the full source snapshot remain recoverable.
